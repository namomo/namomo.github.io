# 📊 동적 차트 빌더 (Dynamic Chart Builder) 기능 구현 계획서

사용자가 데이터를 입력하고 차트 종류를 선택한 뒤, 생성 요청을 하면 실시간으로 차트를 구현하고 이미지로 저장할 수 있는 단계적 차트 빌더 기능의 기획 및 설계 문서입니다.

---

## 1. 🎯 주요 기능 및 요구사항 (100% Full-Width 레이아웃 개편)

### 1단계: 📝 데이터 입력 (가로 100% 대형 테이블 에디터)
* **Full-Width 그리드 에디터**:
  * 데스크탑 해상도에서 화면 가로 폭 100%를 활용하는 대형 데이터 에디터 테이블.
  * **컴팩트한 행 삭제 버튼 (좌측 이동)**:
    * 행 삭제(`Trash2`) 버튼을 테이블의 가장 첫 번째 열(맨 좌측)로 배치하여 직관적인 행 관리를 지원합니다.
  * **직관적인 열 추가 버튼 (우측 이동)**:
    * 테이블의 가장 오른쪽 끝 열 헤더에 `[열(계열) 추가]` 버튼을 위치시켜, 행 추가(테이블 하단)와 대칭되도록 열 추가는 테이블 우측에서 직관적으로 일어나게 합니다.
  * **통합 제어부 (헤더 배치)**:
    * 기존 하단의 별도 카드에 있던 **`[차트 생성 및 반영]`** 버튼과 **`[초기화]`** 버튼을 데이터 테이블 헤더 영역(제목 우측)으로 이동시켜 접근성을 향상시킵니다.
    * 이중 Y축 토글 옵션 역시 헤더 또는 헤더 버튼군 옆 공간에 미니멀하게 통합합니다.

### 2단계: 🚀 차트 생성 및 대형 뷰어 (가로 100% 레이아웃)
* **대형 차트 미리보기**:
  * 데이터 입력창 아래에 가로 100% 폭을 채우는 대형 차트 뷰어를 배치하여 시각적 몰입감과 세밀한 데이터 식별 성능을 확보합니다.
  * 마우스 오버 시 즉각 수치를 노출하는 툴팁 및 상단 중앙 범례(Legend)가 가로폭 확보로 인해 온전히 표출됩니다.

## 2. 🛠 기술 스택 선정 및 아키텍처 설계

### A. 차트 라이브러리: **@mui/x-charts (합성 컴포넌트)**
* **반응형 가로폭 수동 주입**:
  * `@mui/x-charts` 의 `ChartsContainer`와 `PieChart`는 가로폭(`width`) 픽셀 값을 필수 요구하므로, `ResizeObserver`를 이용해 부모 박스의 width를 감지하여 상태(`chartWidth`)로 동적 전달합니다.
  * 툴팁 정상화를 위한 `<ChartsAxisHighlight x="band" />` 컴포넌트를 조립 경로 상에 반드시 추가합니다.
